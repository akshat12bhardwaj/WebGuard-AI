# WebGuard AI Chrome extension

Load this directory unpacked through Chrome extensions with Developer mode enabled. Start the local backend on port 8000 and reload the extension after changes. No build or npm installation is required.

Manual toolbar checks inspect bounded DOM structure using rules. Automatic checking is opt-in and URL-only. The monochrome popup, responsive report, notifications and reduced-motion workflow remain supported.

See [quick start](../README.md), [architecture](../docs/ARCHITECTURE.md), [permissions and privacy](../docs/SECURITY_AND_PRIVACY.md) and [browser verification](../docs/TESTING.md).
