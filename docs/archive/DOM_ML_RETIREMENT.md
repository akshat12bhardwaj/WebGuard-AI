# DOM ML retirement

DOM machine learning was investigated and discontinued. No candidate was promoted. The active product uses the original URL model, URL rules, deterministic DOM rules and threat intelligence.

Removed research, datasets, candidate models and historical documents are preserved in the owner's external local recovery archive. That archive and its local manifests are intentionally excluded from GitHub. Original production URL weights are unchanged; private research and historical source archives remain local. Never execute archived phishing pages or load untrusted serialized models.
